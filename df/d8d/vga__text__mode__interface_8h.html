◆ copyZeroTerminatedCharArrayToEvenPositionsInCharArray()

void copyZeroTerminatedCharArrayToEvenPositionsInCharArray ( char * input_array,
char * output_array )

Copies every element of one array to every even position in the output array until it encounters a 0.

input_array = [a,b,0] and input_array = [c,d,e,f] wil make output_array become [a,d,b,f] This function is mostly to help with VGA text mode.

Parameters
input_arrayA pointer to the start of the zero-terminated input array.
output_arrayA pointer to the start of the output array
Warning
The input array MUST be zero-terminated.
Note
Does not change the odd values in the output array.
Deprecated
Use VgaTextModeInterface.Print instead
